# Integration

- [AWS Terrain Tiles](aws-terrain-tiles.md) - Keyless, free elevation tiles on AWS Open Data for the optional terrain elevation. The default build is EU-DEM in Portugal and the undocumented v2 build is SRTM there; zoom 13 is enough for 25–30 m data.
